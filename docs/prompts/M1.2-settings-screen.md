## Goal
A mouse-operable settings panel, built so adding another boolean setting later is cheap. It starts with exactly one option: **Show grid**, which controls the grid wireframe added in M1.1.

## Plan-mode decision (needs my approval)
Compare the approaches for the UI and recommend one with reasons, before coding:
- libGDX Scene2D UI (already part of libGDX, no new dependency, but needs a skin set up; say how you would create it with minimal assets).
- Dear ImGui bindings for libGDX (third-party dependency; ask first, and tell me the exact dependency and its maturity).
- Anything simpler that still gives a mouse-clickable checkbox.
  Prefer the smallest approach that works. A new dependency needs my explicit approval in the plan.

## Acceptance
- A key opens and closes the settings panel (suggest `Esc` or `F1`; tell me which), and the HUD shows a small hint for it.
- The panel has one checkbox, "Show grid", that takes effect immediately. Default is on, as in M1.1.
- **Clicks and scrolls inside the panel do not pan or zoom the map.** Input must not leak through to the camera.
- Settings live in a small model class in `core` (for example `ViewSettings` with boolean fields), not hard-coded in the renderer. The renderer reads from it. Adding a new boolean later means one field plus one checkbox row.
- No persistence between runs in this story.
- No change to `sim`.

## Constraints
- `core` only. No other settings or options besides "Show grid".
- If you add pure logic, keep it testable and add a unit test.

## Verify and report
`./gradlew build` passes.
