## Goal
The fixed overlay in the upper-left corner becomes the **Inspector** — a utilitarian data panel showing everything about the hovered tile in one place, so the player never has to hunt for information. This story renames it, titles it, and adds the water data that's now available after static water rendering landed.

## Vocabulary
- **Inspector** (or Inspector panel): the fixed upper-left overlay showing global stats and per-tile data. Previously called "HUD" in the code.
- **HUD**: reserved for a future tile-attached overlay drawn on the map near the hovered tile. Does not exist yet. Do not use "HUD" for the inspector in any new code or comments.
