## Goal

- The overlay lists **every current mapping**. First read the input code and verify each one, then write the list. Do not invent or assume mappings. The expected list is: WASD and arrow keys pan, mouse drag pans (confirm which button), scroll wheel zooms, `N`/`P` cycle maps, `F1` toggles the settings panel, `?` toggles this help. Report anything you find that isn't on this list.
- The mapping list is **hand-maintained in one place** (for example a small class holding keys and descriptions as plain data), not scattered through the UI code.
- Use the existing Scene2D setup and skin from M1.2. No new dependencies.
- Choose the simplest input behavior while the overlay is open. I suggest non-modal: camera controls keep working. Tell me which you chose.
- The HUD shows a small "? help" hint.
- The overlay and the F1 settings panel don't break each other (either can be open, or both, without errors or stuck input).
